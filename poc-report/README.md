# 三天報告工作包

這些空白模板對應主方案既有工作，不增加測試。尚無公司實測結果；所有「待填」都不能當成發現。

到公司後，將整個 `poc-report` 放在待分析 repo **外面、與 repo 同層**。主方案的 `../poc-report/` 即指這裡。模板／結果不作為 A、B、C 的分析輸入，以免工具讀到其他組答案。

## 使用順序

1. 第一天：填 [環境](00-environment.md)，確認 [兩題](01-questions.md)。
2. 依主方案執行 A → 建置 → B/C。六個 [runs](runs/) 檔已各自放好完整 prompt，只複製標示的 prompt 區塊進 Claude Code。
3. 每輪保存 R0、R1 與用量。原始回答不覆寫；自己的判斷寫在另一欄。
4. 第二天：填 [主張查核](evidence/claims.md) 與 [發現整理](findings.md)。有做記憶／更新檢查才填對應 evidence 檔。
5. 第三天：用 [英文投影片草稿](slides.md) 與 [中文講稿](script-zh.md) 填入確認過的結果。
6. 卡住或需要整理給其他 agent 時，使用 [支援手冊](使用支援.md)。

**唯一排程依據：**主方案第 0.1 節。版本、指令與停止條件以主方案為準；本工作包只將紀錄與提問具體化。

不必逐欄填滿。缺少量測填 NA；未做的項目標「未測」，不要花時間補齊格式。
