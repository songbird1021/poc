# 固定的兩個問題

案例：Golden 可搜尋到，但建立 Second Form 時不能選。

開始前可改成專案真實名稱；如更換案例，同步修改六個 runs 檔的正文，三組必須一致。不要把已知答案或某組結果補進其他組的 prompt。

## Q1

請說明建立 Second Form 時，從搜尋 Golden 到畫面判定 selectable／disabled 的流程。
請指出觸發位置、資料如何傳遞、判斷發生在哪裡，以及下一個值得查核的來源。

## Q2

Golden 已出現在搜尋結果卻不能選，具體可能由哪些程式條件造成？
請逐項列出可確認的欄位、條件、判斷位置與來源。
哪些業務理由有來源支持，哪些目前只能推測？

## 共同要求

請用本專案的具體名稱，不要只重述功能名稱。
每個重要主張附來源位置；無法定位就標成未知。
區分程式目前行為、文件描述與推論。
不要修改業務程式碼。可保留工具原生分析／memory 產物，並列出本輪寫入哪些檔案。

## R1 統一追問

現在請允許直接讀取 source code、tests、config，查核剛才最重要的三項主張。
補上支持它們的具體來源，尋找遺漏的分支、例外與矛盾。
修正缺乏支持的說法，區分工具產物已提供的資訊與這次回 source 才查到的資訊。
請列出仍未確認之處，不要把合理推測當成已知業務規則。

Agent 在 R1 查三項主張；人工紀錄只挑每個 session 最重要的兩項，兩者不是同一工作量。
